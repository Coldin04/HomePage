## Cyime

轻快写作，随云流动，支持多方案图片上传的云文档。

Cyime是一个基于Web的在线Markdown编辑器，支持实时预览、导出PDF、导出HTML等功能。它旨在为用户提供一个简洁、高效的Markdown写作环境。其特色功能为可在编辑时安全的私有存储你的图片，在发布时支持一键同步到图床，并提供多种格式的导出方案。

## JustRead

JustRead 是一个适配了 esp32-s3 墨水屏设备，与他人共同完成。支持例如 [Read Pico](https://dot.mindreset.tech/docs/read_pico) 设备阅读器固件，其特性是提供快速翻页刷新和简介好用的用户界面。支持多种电子书格式，并提供个性化的阅读设置，如字体大小、行间距、主题颜色等。JustRead 旨在为用户提供快速、舒适的阅读体验。

## InkReaderLink

InkReaderLink 是面向电子墨水阅读设备及兼容固件的设备桥接层（device bridge），为多种客户端和服务端提供统一设备能力。现已适配 [Read Pico阅读器](https://dot.mindreset.tech/docs/read_0) 的多种固件，接入 InkReaderLink SDK 的客户端可通过 InkReaderLink 提供的能力便捷管理 Read Pico 等电子书设备的文件系统、阅读器设置、阅读进度等信息。

{% iconLink "fab fa-github", "InkReaderLink", "https://github.com/Coldin04/Cyime", "icon-only-link" %}

## Pico Manager


Pico Manager 是一个基于 InkReaderLink 的 Read Pico 设备管理工具，提供图形化界面，方便用户管理 Read Pico 设备的文件、设置和阅读进度等信息。它支持多种操作系统，并提供简洁易用的用户体验。
